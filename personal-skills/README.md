# Personal skills (optional global install)

Not part of the default six OS skills. Install when you build or review UI and want a separate slash command from prose `no-ai-slop`.

| Skill | Slash | Install |
| --- | --- | --- |
| `ui-anti-slop` | `/ui-anti-slop` | `./install-global.sh --personal` |

Source lives here so collaborators get the same skill name and `SKILL.md` `name:` (`ui-anti-slop`). Do not duplicate the vendored prose skill in `skills/no-ai-slop/`.
